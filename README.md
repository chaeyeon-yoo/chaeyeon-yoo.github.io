## ♿ Accessibility

이 포트폴리오 자체도 접근성 기준을 지키며 만들었습니다.

- 키보드 포커스 표시(`:focus-visible`), 본문 바로가기(skip link)
- `prefers-reduced-motion` 대응
- WCAG AA 명도 대비 기준 준수
- 시맨틱 heading 구조 (h1 → h2 → h3)
